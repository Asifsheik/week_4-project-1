# Simple Registration Form with JavaScript Validation

## Project Description

This project is a simple registration form created using HTML, CSS, and JavaScript. It allows users to enter their Name, Email, and Password. When the user submits the form, JavaScript performs real-time validation to ensure that all input fields contain valid information.

## Features

* Simple and user-friendly registration form.
* Name field validation.
* Email format validation.
* Password validation.
* Real-time input validation using JavaScript.
* Displays error messages for invalid inputs.
* Displays a success message when all fields are valid.

## Technologies Used

* **HTML5** – To create the registration form structure.
* **CSS3** – To style the registration form.
* **JavaScript** – To perform real-time form validation.

## Form Fields

1. **Name:** Accepts the user's full name.
2. **Email:** Accepts a valid email address.
3. **Password:** Accepts a password that meets the required conditions.

## Validation Rules

* Name must not be empty.
* Email must be in a valid email format.
* Password must contain at least 8 characters.
* All fields are required.
* Appropriate error messages are displayed when validation fails.

## Expected Output

* If the user enters invalid information, error messages are displayed.
* If all fields contain valid information, a registration success message is displayed.

## Conclusion

This project demonstrates how to create a simple registration form using HTML, CSS, and JavaScript. It helps understand form handling, input validation, event handling, and basic client-side validation techniques.
